🇬🇧 English: Advanced Network Forensic Acquisition Framework
Overview
This framework provides a theoretical and professional architecture for remote network digital forensics and incident response (DFIR). Designed with a dual-node controller-agent concept, it enables interactive IP targeting, secure socket connection management, recursive file-system traversal, chunked binary streaming, and cryptographic hash verification (SHA-256) to maintain a strict legal Chain of Custody.
Key Features
 * Interactive Looping Interface: Prompts operators for target IP addresses and ports within a continuous operational loop.
 * Stream Telemetry: Real-time terminal progress bars and byte-transfer statistics.
 * Chain of Custody: Automatically generates cryptographic SHA-256 integrity hashes and structured JSON manifests for every acquired artifact.
 * Secure Architecture: Modular design prepared for TLS/SSL socket wrapping and mutual certificate authentication.
Usage
python3 forensic_controller.py

🇮🇹 Italian (Italiano): Framework Avanzato di Acquisizione Forense di Rete
Panoramica
Questo framework fornisce un'architettura teorica e professionale per la digital forensics di rete remota e la risposta agli incidenti (DFIR). Progettato con un concetto dual-node (controller-agente), consente il targeting IP interattivo, la gestione sicura delle connessioni socket, l'attraversamento ricorsivo del file system, lo streaming binario a blocchi e la verifica crittografica tramite hash (SHA-256) per preservare la rigorosa catena di custodia (Chain of Custody).
Caratteristiche Principali
 * Interfaccia a Ciclo Interattivo: Richiede all'operatore indirizzi IP e porte di destinazione all'interno di un loop operativo continuo.
 * Telemetria in Streaming: Barre di avanzamento del terminale in tempo reale e statistiche di trasferimento dei byte.
 * Catena di Custodia: Generazione automatica di hash di integrità SHA-256 e manifest JSON strutturati per ogni artefatto acquisito.
 * Architettura Sicura: Struttura modulare predisposta per il wrapping socket TLS/SSL e l'autenticazione a certificati reciproci.
Utilizzo
python3 forensic_controller.py

🇫🇷 French (Français): Framework Avancé d'Acquisition Forensique Réseau
Vue d'ensemble
Ce framework propose une architecture théorique et professionnelle pour l'investigation numérique réseau à distance et la réponse aux incidents (DFIR). Conçu selon un modèle à double nœud (contrôleur-agent), il permet le ciblage IP interactif, la gestion sécurisée des sockets, le parcours récursif du système de fichiers, le streaming binaire par blocs et la vérification cryptographique par hachage (SHA-256) afin de garantir la stricte chaîne de custody (chaîne de traçabilité des preuves).
Caractéristiques Clés
 * Interface de Boucle Interactive : Invite l'opérateur à saisir les adresses IP et ports cibles dans une boucle d'exploitation continue.
 * Télémétrie de Flux : Barres de progression du terminal en temps réel et statistiques de transfert d'octets.
 * Chaîne de Traçabilité (Chain of Custody) : Génération automatique de hachages d'intégrité SHA-256 et de manifestes JSON structurés pour chaque artefact acquis.
 * Architecture Sécurisée : Conception modulaire prête pour le chiffrement TLS/SSL et l'authentification mutuelle par certificat.
Utilisation
python3 forensic_controller.py
